# 运营工作台优化

入口：`/ops/`。使用现有 OPS_ADMIN_TOKEN 管理鉴权，访问令牌只保留在页面内存。

## 已实现

- 按模块显示总览、反馈、资料审核、首页问题、发布历史与说明；移动端保留导航。
- 总览展示待处理反馈、待审核资料、当前实例请求与失败数，以及 AI 配置和存储状态。统计不表示活跃用户或留存。
- 反馈和资料支持关键词搜索、状态筛选、每页八条；未提交说明在筛选和刷新时保留。
- 首页问题支持草稿保存、编辑预览、线上版本对照、发布、放弃修改与历史回滚。
- 操作记录以中文表格显示；当前展示最近一百条审核操作。
- 保存期间防止重复提交，保留原本禁用的状态按钮；请求超时明确提示结果未确认；版本冲突保留输入。
- 退出或关闭页面前提示未保存内容。归档仍需确认，归档会删除正文。

## 验证与边界

Playwright 使用本地模拟接口验证总览、反馈搜索、分页、筛选后草稿保留、提案状态过滤、保存请求载荷、版本冲突保留输入和 390px 窄屏页面宽度。JS 语法与 git diff 空白检查通过。模拟数据不进入正式代码。

本次未连接线上 MySQL，也未执行线上发布、回滚或归档。用户列表、套餐配置、积分调整、支付对账、多管理员权限仍未开放；需要相应的服务端权限和操作审计后再实现，不能把当前工作台视作完整商业化后台。
