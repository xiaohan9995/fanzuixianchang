# 中文餐食与数据服务评测

manifest 包含100个待采样场景，不是已测图片或准确率报告。当前未获真实图片/称重参考，也未接入付费竞品接口；禁止将此清单宣传为100组实测通过。

每个场景取得实际餐图（包装需标签、订单注意脱敏）、用户真实食用描述，记录来源许可。可取得称重/配方/标签参考的填写 referenceKcal 和 referenceBasis，其余保留空值。

同批样本分别跑当前模型及候选视觉模型，再对成熟食物服务比较：识别菜品是否正确、份量修正次数、可用率、热量误差与区间覆盖、P95时延、单次费用、字段完整性。食品API单独测试相同中文查询和商品信息，不把查询命中率等同餐图准确率。

授权接口优先评估薄荷科学 https://ai.boohee.com/ ，备选 FatSecret https://platform.fatsecret.com/platform-api 。当前只有官方文档研究，未登录测试。开通前需确定中国地区权限、调用价格、缓存和历史记录持久化许可、退出后记录权利。无账号时不能用猜测接口返回假成功。

人工判定结果按 JSONL 保存，字段见 `scripts/score-meal-estimates.py --help`，执行该脚本输出分场景报告。没有参考值的样本不计算热量误差；拒识与误识都必须报告。模糊、空白、非食物、隐藏标签、同名不同做法另建异常测试集。

发布门槛：清晰日常样本可用率目标90%；标签算术与参考舍入一致；主流程一次确认记录；常用份量修正不超过两次点击。误差按各类别展示，不用一个总平均掩盖失败类别。必须进行Android/iOS键盘、选择照片、网络中断及跨设备恢复验证。
